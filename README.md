# Mehro Nisa Malik - Registered Clinical Dietitian & Nutritionist

Official practice website for **Mehro Nisa Malik (RD)**, Registered Clinical Dietitian & Certified Nutrition Consultant. Specializing in medical nutrition therapy, PCOS & hormonal balance, diabetes management, gut health, and personalized clinical nutrition programs.

## 🌟 Key Features

- **Evidence-Based Medical Nutrition Therapy:** Dedicated sections for PCOS, Metabolic Health, Diabetes, and Digestive Wellness.
- **Interactive Consultation Booking:** Patient booking interface with online telehealth and in-person consultation options.
- **WhatsApp Direct Integration:** Instant messaging link for swift clinic appointment scheduling and patient inquiries.
- **Responsive & Modern Design:** Built with Tailwind CSS and designed following the *Serene Clinical Luxury* aesthetic.
- **Local Dev Server:** Built-in zero-dependency Node.js HTTP server.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+)

### Running Locally
```bash
# Start the web server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
